# Tanks

This project is a custom scale arcade cabinet. Made using Python and C++, it mixes custom hardware and custom software in a small and fun project. The Esp32 collects data from the custom controller circuits and sends them as a serialized packet. Python using Pyserial deserializes them and parses the data into controller actions. 

The game is a duel style two player tanks game where each player is trying to shoot missles which bounce off the walls to hit and destroy the other player's tank.


##Overview
- Onshape: modeling
- 3d printer: cabinet
- Esp32: custom controls and serial communication
- Raspberry Pi 5: Running Display, Pygame, and receiving serial communication.
- Python: Custom tanks two player arcade made with Pygame
- Pixilart: Sprites and ui!

- Adobe Illustrator: drawing Cabinet artwork
- Rolland Large Format Vinyl Printer: Making Custom Cabinet artwork vinyl sheets
